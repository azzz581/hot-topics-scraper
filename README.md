# 多平台热点抓取工具 (hot-topics-scraper)

自动抓取各大平台热搜 / 热榜数据的 Python 脚本，专为短视频选题和同城流量运营设计。

## 功能

- 并发抓取 7 个平台：微博、知乎、百度、抖音、头条、B站、华尔街见闻
- 每次运行输出两份文件：
  - `热点日报_日期_时间.md` —— 带跳转链接的表格报告（人读）
  - `热点数据_日期_时间.json` —— 结构化数据（程序处理用）
- 内置重试机制（3 次）、SSL 容错、并发控制（3 线程）

## 环境要求

- Python 3.8+
- 依赖：`requests`

```bash
pip install requests
```

## 使用方法

```bash
python hot_topics_scraper.py
```

运行后结果自动保存在 `output/` 目录，每次生成带时间戳的新文件，不会覆盖历史。

## 平台覆盖情况

| 平台 | 状态 | 说明 |
|------|------|------|
| 知乎热榜 | ✓ 稳定 | API + HTML 双方案 |
| 百度热搜 | ✓ 稳定 | 多接口回退 |
| 抖音热搜 | ✓ 稳定 | 移动端 SNSSDK 接口 |
| 头条热榜 | ✓ 稳定 | 官方热榜接口 |
| B站热搜 | ✓ 稳定 | 移动端趋势接口 |
| 华尔街见闻 | ✓ 稳定 | 财经快讯 |
| 微博热搜 | △ 受限 | 反爬较严，已留多套备选方案，换网络环境或加 Cookie 可解 |

## 定制化

脚本顶部 `配置区` 可直接调整：

- `TOP_N`：每个平台抓取条数（默认 20）
- `TIMEOUT`：请求超时秒数（默认 15）
- `MAX_RETRIES`：失败重试次数（默认 3）

## 典型用途

- 短视频代运营：每天抓取热点，批量生成选题
- 同城实体流量：筛选本地相关热点做内容
- 选题库搭建：JSON 数据可直接入库做去重 / 汇总
